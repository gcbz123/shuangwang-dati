# 2026-05-23

## 项目全面审查与修复

### 修复的 P0 严重问题
1. **`examOrchestrator.js` parseAnswerLetters 类型误用** — `parseAnswerLetters()` 返回 Array<Object> 但 answerQuestion 中当作字符串使用，导致自动考试崩溃。已重写 answerQuestion 方法适配数组返回值。
2. **前端密码硬编码** — `web/index.html` 中 `ADMIN_PASSWORD` 直接暴露在源码中。已添加后端 `adminAuthMiddleware`（Bearer Token 认证）、`POST /api/auth/login` 端点，所有敏感 API 路由（题库、考试、报告、监控、环境配置）均需认证。前端改为调用登录 API 获取 token 并存到 localStorage。
3. **Navigator convertJQuerySelector 跳过 :contains() 选择器** — 所有含 `:contains("文本")` 的选择器被直接跳过。已修复 `navigator.js` 不再跳过，并在 `PuppeteerDriver` 的 `waitForElement` 和 `click` 方法中实现了 `:contains()` 的 JS evaluate 查找。

### 修复的 P1 问题
4. **端口号统一为 3500** — `env.conf` 清理尾部空格，`AGENTS.md` 更新端口文档。
5. **题型常量统一** — `config.js` QUESTION_TYPES 改为 `'single'/'multiple'/'judgment'/'short_answer'`（与题库存储值和 detectQuestionType 返回值一致），`question_bank.json` 批量迁移 4455 条记录，`reportGenerator.js` 同步更新。
6. **生产环境 CORS 安全** — 生产环境未配置 ALLOWED_ORIGINS 时不再回退到 `*`，改为不设置跨域头（依赖浏览器同源策略）。

### 修复的 P2 问题
7. **`reportGenerator.js`** — 移除对 `session.screenshots`（不存在属性）的引用。
8. **`routes.js`** — 移除 3 处重复的 `require('fs')` / `require('path')`。
9. **Health check 日志** — 改为仅开发环境输出 debug 级别，不再每次 health check 都写 info 日志。
10. **`package.json`** — 修复已废弃的 Jest `--testPathPattern` 参数为 `--testPathPatterns`。
