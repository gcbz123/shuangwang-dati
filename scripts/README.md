# 📜 自动答题脚本使用说明书

## 📦 脚本简介
本目录包含答题助手系统配套的浏览器自动化脚本，支持在任意网页上通过快捷键获取题目源码并自动填充答案。

### 脚本版本说明

| 文件名 | 版本 | 适用场景 | 特点 |
|--------|------|----------|------|
| `脚本猫/auto-answer.user.js` | 通用版 v1.0 | 所有考试系统 | 轻量稳定，支持键盘快捷键控制 |
| `脚本猫/auto-answer-enhanced.user.js` | 增强版 v2.0 | 复杂考试系统 | 功能更丰富，支持更多题型和 DOM 结构 |
| `管理后台版/auto-answer.user.js` | 后台专用 v1.0 | 答题助手管理后台 | 专用于 `localhost:3000/admin.html`，提供批量答题功能 |

---

## 🛠️ 安装步骤

### 方式一：使用脚本猫 (ScriptCat) - 推荐
1. 下载并安装 **脚本猫** 浏览器扩展
   - Chrome: 访问 Chrome 应用商店搜索 "ScriptCat"
   - 或从本系统 `web/tools/` 目录下载离线安装包
2. 点击浏览器右上角脚本猫图标 → **添加新脚本**
3. 将 `auto-answer.user.js` 的代码完整复制粘贴到编辑器中
4. 点击 **保存** 并启用脚本

### 方式二：使用 Tampermonkey (油猴)
1. 安装 Tampermonkey 扩展
2. 点击扩展图标 → **添加新脚本**
3. 粘贴脚本代码并保存 (Ctrl+S)

## ⌨️ 快捷键操作

安装成功后，在任意考试页面可使用以下快捷键：

| 快捷键 | 功能说明 |
|--------|----------|
| `-` (减号) | **获取源码**：抓取当前页面题目 HTML 并发送到后端解析 |
| `+` (加号) | **开始答题**：根据后端返回的答案自动点击选项或填充文本 |
| `*` (星号) | **隐藏面板**：隐藏/显示悬浮控制面板 |
| `/` (斜杠) | **停止运行**：中断当前正在执行的答题任务 |
| `D` (大写) | **调试模式**：在控制台输出详细调试信息 |

---

## 🚀 使用流程

1. **打开考试页面**：进入在线答题系统
2. **获取源码**：按下 `-` 键，脚本会自动抓取题目 HTML
3. **等待解析**：后端匹配题库并返回答案（通常 1-3 秒）
4. **自动答题**：按下 `+` 键，脚本自动填充答案
5. **下一题**：重复步骤 2-4，或手动点击"下一题"

## ⚙️ 高级配置

### 修改 API 地址
如果答题助手后端不在 `localhost:3000`，请修改脚本开头的配置：
```javascript
const API_URL = 'http://你的服务器IP:3000';
```

### 自定义 DOM 选择器
如果考试系统页面结构特殊，可在脚本中调整选择器配置：
```javascript
const CONFIG = {
  questionSelector: '.ti',      // 题目容器选择器
  optionSelector: '.ant-radio-wrapper', // 选项选择器
  nextButtonSelector: '.next-btn'       // 下一题按钮
};
```

## ⚠️ 注意事项

1. **后端服务必须运行**：使用前请确保答题助手后端 (`node index.js`) 正在运行
2. **题库需提前导入**：答案匹配依赖题库数据，请先通过管理后台导入题库
3. **浏览器兼容性**：推荐使用 Chrome 120+ 或 Edge 浏览器
4. **防检测提醒**：部分考试系统有反作弊检测，建议：
   - 开启脚本中的"随机延迟"功能
   - 不要设置过快的答题速度
   - 避免在非授权考试中使用

## 🆘 常见问题

**Q: 按下快捷键没有反应？**
A: 请检查：
- 脚本是否已启用（扩展图标显示数字角标）
- 当前页面 URL 是否匹配脚本的 `@match` 规则
- 浏览器控制台 (F12) 是否有报错信息

**Q: 答案匹配不准确？**
A: 请检查：
- 题库中是否存在该题目
- 匹配相似度设置是否合理（建议 0.20-0.25）
- 题干提取是否完整（可在控制台查看调试信息）

**Q: 如何更新脚本？**
A: 从本系统 `scripts/` 目录获取最新版本，覆盖原有脚本代码即可。
