# 2026-05-23

## 将油猴脚本移植为 Chrome 插件

- 源文件：`auto-answer-enhanced.user.js` v2.2（支持局网考试 ASP.NET + 职教考试 Ant Design Vue）
- 输出目录：`chrome-extension/`
- 文件清单：`manifest.json`（MV3）、`content.js`（核心逻辑）、`background.js`（Service Worker）、`popup.html/js`（弹窗界面）
- 主要适配点：
  - `GM_notification` → `chrome.runtime.sendMessage` → `chrome.notifications`
  - `GM_addStyle` → 动态 `<style>` 标签
  - `eval()` → `new Function()`（MV3 CSP 限制）
  - 配置持久化：内存 → `chrome.storage.local`
  - 新增 Popup 弹窗界面（status 显示 + 按钮操作）
- 图标：用纯 Node.js（zlib）生成渐变色 PNG，无需第三方依赖
- 图标 v2：改为圆形蓝紫渐变 + 白色黑体"晖"字
- 翻页 Bug 修复：Chrome content script 沙箱隔离导致 `__doPostBack is not defined`
  - 原因：content script 无法访问页面主世界的 JavaScript 对象
  - 尝试1：`nextLink.click()` → CSP 拦截 `javascript:` URL
  - 尝试2：`chrome.scripting.executeScript({world:'MAIN', func})` → func 自动 strict mode，ASP.NET `_doPostBack` 访问 `arguments.caller` 报错
  - **最终方案**：`page-world.js` 通过 `chrome.scripting.executeScript({world:'MAIN', files:['page-world.js']})` 注入（非 strict mode），content script 通过 `window.postMessage` 发指令，page-world.js 执行 `__doPostBack` 并回传结果
  - `waitForPageReady()` 同样改为 postMessage 通信，page-world.js 在非 strict 环境监听 `Sys.WebForms.PageRequestManager.endRequest`
  - 油猴脚本同步改为 `.click()` 方式（油猴在主世界运行，无 CSP 限制）
- manifest.json 修复：`ws://localhost:3501` 在 host_permissions 中非法，已移除
- autoNextPage 默认值改为 true
- 翻页最终修复（根本原因）：`initPanel()` 中 `ensurePageWorldInjected()` 调用在 `detectExamType()` 之前，`state.examType` 为 null 导致永不执行。修复为正确顺序：先 detectExamType() 再 ensurePageWorldInjected()
- 代码审查清理：移除遗留调试日志；`page-world.js` 加 `remove_endRequest` 防监听器累积；`background.js onInstalled` 不再覆盖 apiUrl/wsPort
