# 智能考试助手 - 浏览器扩展版

## 安装步骤

### Chrome / Edge
1. 打开 `chrome://extensions/` 或 `edge://extensions/`
2. 开启右上角 **"开发者模式"**
3. 点击 **"加载已解压的扩展程序"**
4. 选择 `huigedehui` 文件夹

### Firefox
1. 打开 `about:debugging#/runtime/this-firefox`
2. 点击 **"临时加载附加组件"**
3. 选择 `huigedehui` 文件夹中的 `manifest.json`

## 功能说明

### 支持考试类型
- **局网考试** (ASP.NET WebForms) - 自动识别 `div[id^="pt"]` 容器
- **职教考试** (Ant Design Vue) - 自动识别 `.ti` 容器

### 使用方法
1. 打开答题页面
2. 按键盘 `-` (减号) 获取页面源码并解析答案
3. 按键盘 `+` (加号) 开始自动答题
4. 按键盘 `*` (星号) 隐藏/显示控制面板
5. 也可以点击扩展图标打开弹窗进行操作

### 快捷键
| 按键 | 功能 |
|------|------|
| `-` | 获取页面源码并解析 |
| `+` 或 `=` | 开始自动答题 |
| `*` | 隐藏/显示控制面板 |

## 注意事项

1. **后端服务必须运行**: 使用前请确保答题助手后端 (`http://localhost:3000`) 正在运行
2. **题库需提前导入**: 答案匹配依赖题库数据
3. **考试类型自动检测**: 扩展会根据页面 DOM 结构自动识别考试类型

## 文件说明

```
huigedehui/
├── manifest.json   # 扩展配置文件
├── content.js      # 内容脚本（注入到页面执行）
├── popup.html      # 弹窗界面
├── popup.js       # 弹窗逻辑
└── README.md      # 说明文档
```

## 技术特性

- **独立运行**: 不依赖 Tampermonkey / ScriptCat
- **自动适配**: 自动识别局网考试/职教考试 DOM 结构
- **拟人化**: 随机延迟模拟人类操作
- **支持暂停/恢复**: 可随时暂停答题
