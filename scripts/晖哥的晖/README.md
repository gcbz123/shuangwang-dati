# 晖哥的助手 — Tampermonkey 插件

支持**局网考试（ASP.NET WebForms）**和**职教考试（Ant Design Vue）**两种平台的自动答题辅助脚本，手动/自动双模式。

**版本**: 2.2 | **作者**: Sisyphus | **文件**: `auto-answer-enhanced.user.js` (1092 行)

---

## 功能概述

1. **悬浮抽屉面板**：面板吸附于屏幕右侧，平时仅露一条彩色边，悬停滑出
2. 按 `-` 获取当前考试页面 HTML 源码 → 发送后端 API 匹配题库
3. 后端返回答案列表，脚本逐题自动点击对应选项
4. 支持**单选 / 多选 / 判断 / 简答**四种题型
5. **自动翻页**（局网考试）：勾选后答题结束自动翻到下一页，续答直至全部完成
6. WebSocket 远程控制接口，支持 Puppeteer 自动模式驱动

## 面板行为

- 悬浮窗**始终吸附**于屏幕右侧边，默认只露出一条渐变加粗边
- 鼠标悬停 → 面板滑出，展示所有控件和状态信息
- 鼠标离开 → 自动吸附隐藏，仅保留颜色条
- 按 `*` 键可完全隐藏/显示面板

## 快捷键

| 按键 | 功能 |
|---|---|
| `-` | 获取当前页面源码，发送后端匹配 |
| `+` | 开始自动答题 |
| `*` | 隐藏/显示控制面板 |
| `/` | 停止答题 |
| `D` | 打印 DOM 调试信息到控制台 |
| `H` | 显示/隐藏快捷键提示 |

## 技术要点

- **悬浮抽屉**：CSS `transform` 控制滑入滑出，停靠右上角，`translateX(calc(100% - 8px))` 仅露 8px 边缘；`:hover` 触发 `translateX(0)` 完全展开；`max-height: calc(100vh - 120px)` 留出底部提交答案区域
- **自动翻页**：通过 `#UpdatePanel1 a[id]` 检测当前页（`text-decoration:none` 标记），调用 `__doPostBack(nextPageId, '')` 翻页；用 `Sys.WebForms.PageRequestManager` 监听 UpdatePanel 刷新完成
- **局网判断题映射**：局网考试 radio value 用 `T`/`F`（True/False），脚本将 `对`→`A`→`T`，`错`→`B`→`F`
- **职教回退机制**：优先 `.ant-radio-wrapper` 容器查找，找不到回退全局 `input[type="radio/checkbox"]`
- **随机延迟**：基准 200ms + 随机因子，模拟人类操作节奏
- **暂停/继续**：答题循环内轮询状态标志，不阻塞浏览器
- **WebSocket 命令集**：`navigate` / `getPageSource` / `click` / `fillInput` / `waitForElement` / `injectScript` / `evaluateScript` / `detectNextButton`
